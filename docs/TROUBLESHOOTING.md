# Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| No application is themed | Hook 80 not installed, or no staged Omarchy theme | `~/.local/bin/omarchy-adwaita-gtk` then `omarchy theme set <name>` |
| Only some GTK3 apps are themed | Those apps use libhandy and/or ship their own stylesheet | Check that `~/.config/gtk-3.0/gtk.css` exists and starts with the `Gtk-Omarchy-Theme-Inheritar` marker; it must be at user priority 800 |
| Headerbar of a libhandy app (GNOME Disks, Evince) is still Adwaita | The generated user CSS is missing the `background` shorthand rule | Regenerate; the layer must contain `.titlebar:not(headerbar), headerbar { … background:#… linear-gradient(…) }` |
| Checkboxes/radios render as solid red blocks | The theme copy points at `assets/…` which does not exist on disk | Regenerate; the file must contain `resource:///org/gtk/libgtk/theme/Adwaita/assets/` (GTK3) and `…/Default/assets/` (GTK4) |
| libadwaita apps (GNOME apps) keep Adwaita colours | `~/.config/gtk-4.0/gtk.css` missing, or deleted by another tool | Re-run the generator; the file must define `@define-color window_bg_color …` etc. |
| Nautilus looks like the generic palette | The extension is not loaded, so nothing registers at 801 | Ensure `nautilus-python` is installed and the extension exists in `~/.local/share/nautilus-python/extensions/` or `/usr/share/nautilus-python/extensions/`; restart Nautilus |
| Nautilus palette does not update live | `~/.cache/omarchy/gtk/nautilus.css` is not being rewritten | Run `~/.config/omarchy/hooks/theme-set.d/70-omarchy-nautilus-palette.sh`; check hook 70 is still installed |
| Disks/Lutris show Adwaita colours after a GTK upgrade | The generated sheet was built against an older GTK | Re-run `omarchy-adwaita-gtk` (also happens automatically on the next theme switch) |
| Everything is Adwaita after selecting HighContrast | Intentional: the generator writes palette-free files when HighContrast is active | Switch back (`omarchy theme set <name>` with HiContrast off) |
| Flatpak apps are not themed | Flatpaks use `~/.var/app/<id>/config` as `XDG_CONFIG_HOME` | Export the layers per app; out of scope (documented limitation) |
| A theme switch produced no change | Hooks are skipped when Omarchy stages no theme | Check `~/.local/state/omarchy/current/theme/colors.toml` exists |
| Want the previous state back | — | `uninstall.sh` removes everything this project owns and restores the previous `gtk-theme` |

## Manual checks

```bash
# which theme name is selected
gsettings get org.gnome.desktop.interface gtk-theme

# what the generator would produce right now
~/.local/bin/omarchy-adwaita-gtk --stdout | head -20

# which files the project generated
grep -rl "Generated by Gtk-Omarchy-Theme-Inheritar" \
     ~/.config/gtk-3.0 ~/.config/gtk-4.0 ~/.local/share/themes/Omarchy-Adwaita 2>/dev/null

# what an installation recorded
cat ~/.local/state/gtk-omarchy-theme-inheritar/install.json
```
